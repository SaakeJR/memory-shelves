# Memory Shelves V1.0

Free browser-based study library with themed rooms, subject bookshelves, topic shelves, and fact books.

## Ready-to-use course

World History I is preloaded. The **Bookshelf** menu contains:

1. Exam 2 - Complete Except Maps (166 yellow-highlighted study books, organized by topic shelves)
2. Exam 2 - Byzantium & Orthodoxy 1 of 4
3. Exam 2 - Islamic World 2 of 4
4. Exam 2 - Medieval Europe 3 of 4
5. Exam 2 - Late Medieval & Renaissance 4 of 4
6. Quiz 2: Pages 33–41 & 46–51

The four Exam 2 parts use the exact same fact books as the complete bookshelf. A correctly placed book in a part also appears completed in the complete bookshelf. Resetting a part also resets those cards in the complete bookshelf. No map questions are included.

## Studying

- Choose a room and bookshelf on the left (above the bookshelf on narrow/mobile screens).
- Under **Shelf selection**, choose **Show all shelves** to study the entire bookshelf, or select a topic to narrow the unsorted stack to that topic.
- Select an unsorted book to read it. Choose its shelf via **Place this book on** and **Place book**, or click a physical shelf.
- For Recall Mode, open the **MODE** dropdown and choose **Recall: think, then reveal**. Use **Reveal answer** before placing.
- Select **Help** for a complete walkthrough. Use **Add study set** to add material generated by ChatGPT.
- Books and progress save to browser local storage. **Settings** contains backup and restore tools.

## GitHub Pages publishing (no code or terminal required)

1. Extract the ZIP. Upload the files INSIDE this release folder, not the folder or ZIP itself.
2. Sign in at https://github.com, then open https://github.com/new.
3. Create a **Public** repository, suggested name `memory-shelves`. Leave auto-generated README, .gitignore, and license disabled because files are provided here.
4. In the empty repository, select **uploading an existing file** (or **Add file > Upload files**).
5. Upload `index.html`, `README.md`, `LICENSE`, `sample-study-set.json`, `study-set-chat-prompt.txt`, and `.nojekyll`. Some systems hide dot-files; the site also works without `.nojekyll` for this static app.
6. Select **Commit changes**.
7. Select **Settings > Pages**. For Source, choose **Deploy from a branch**. Select branch **main** and folder **/(root)**. Save.
8. When GitHub Pages finishes, visit `https://YOUR-USERNAME.github.io/memory-shelves/` and check in a private/incognito browser session.
9. Share that URL. Students do not need a GitHub account.

## Things to know

The site is static and free for public repositories on GitHub Pages. Each browser saves its own books and study progress; nothing is synchronized between devices. Export a backup in Settings before clearing site data or switching computers. The original history data are condensed from the provided exam study guide, and are not an independently verified historical reference.

This release does not require any build step, package manager, API key, or backend.


## Highlight verification

This pre-launch V1.0 study content was audited against yellow-highlighted fragments of the uploaded FA26 Exam 2 study packet. Study-card bodies preserve the highlighted wording as selected fragments, not reconstructed full paragraphs. Fragments may have gaps where words were not highlighted. Quiz 2 includes printed pages 33–41 and 46–51, and date study cards only from the page 33 and 41 timelines. No map study cards are provided. The initial 93-card Quiz 2 beta was edited down to 89 in a later version because nine cards were removed and five added, without a highlight-completeness check. This release reconstructs the cards from the highlights. Existing built-in card wording is corrected during migration, preserving attempts/placements. Student-authored cards are not changed.

## Why Quiz 2 card counts changed

Beta 0.4 had 93 cards. An intermediate release removed nine and added five, leaving 89. That edit was not based on a complete source audit. The highlight-only rebuild has 87 Quiz 2 books. Book counts depend on how highlighted concepts are grouped into cards, not the number of questions on the actual quiz. Only source-highlighted material is included in card bodies.
